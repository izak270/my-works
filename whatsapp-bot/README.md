# WhatsApp Agent Bot — בוט וואטסאפ עם סוכן פעיל

בוט וואטסאפ מבוסס [`whatsapp-web.js`](https://wwebjs.dev/) שעבר מ"האזנה בלבד" ל**סוכן פעיל**: הוא מאזין להודעות נכנסות, מעביר אותן לאורקסטרטור מבוסס LLM (Claude), ושולח תגובה חזרה לאותה שיחה — עם התנהגות "אנושית" ומנגנוני בטיחות מלאים.

## ארכיטקטורה

```
הודעה נכנסת ──▶ שרשרת סינונים ──▶ processWithAgent (Claude API) ──▶ sendStateTyping + השהיה ──▶ sendMessage
                    │
                    └─ Kill Switch / allowlist / מילת מפתח / קבוצות
```

| קובץ | תפקיד |
|---|---|
| `src/index.js` | חיבור לוואטסאפ, שרשרת הסינונים, חיווי אנושי ושליחת התגובה |
| `src/agent.js` | הסוכן — קריאה ל-Claude API עם היסטוריית שיחה לכל צ'אט |
| `src/dashboard.js` | דשבורד ווב — סטטוס, צימוד, לוג אירועים והדלקה/כיבוי מהדפדפן |
| `src/config.js` | כל ההגדרות ממשתני סביבה |

## איך זה מחובר למספר שלך — ומה אתה רואה

הבוט מתחבר לחשבון הוואטסאפ שלך כ**מכשיר מקושר**, בדיוק כמו WhatsApp Web בדפדפן. המשמעות:

- **רואים הכל** — כל הודעה נכנסת וכל תגובה שהבוט שולח מופיעות בשיחות הרגילות שלך, בטלפון וב-WhatsApp Web במקביל. תגובות הבוט נראות כהודעות יוצאות מהחשבון שלך (אפשר לסמן אותן עם `BOT_REPLY_PREFIX`, למשל 🤖, כדי להבחין בינן לבין הודעות שכתבת בעצמך).
- **שליטה מלאה** — ה-Kill Switch עובד מהטלפון שלך מכל שיחה, ובנוסף אפשר בכל רגע לנתק את הבוט לגמרי מתוך וואטסאפ: **הגדרות ← מכשירים מקושרים ← ניתוק המכשיר**. הניתוק מיידי ולא דורש גישה לשרת.
- **המספר נשאר אצלך** — הבוט לא "מחזיק" את המספר; הוא רק סשן מקושר שאתה מאשר מהטלפון ויכול לבטל בכל עת.

## התקנה והפעלה

```bash
cd whatsapp-bot
npm install
cp .env.example .env   # ערוך את הקובץ: מפתח API, המספר שלך, מספרים מורשים וכו'
npm start
```

**שתי דרכי חיבור** (החיבור מאושר תמיד מהטלפון שלך):

1. **קוד צימוד לפי מספר (מומלץ)** — הגדר את `PAIRING_PHONE_NUMBER` ב-`.env` עם המספר שלך (פורמט בינלאומי ללא +, למשל `972501234567`). בהפעלה תקבל קוד בן 8 תווים; הזן אותו בטלפון: וואטסאפ ← הגדרות ← מכשירים מקושרים ← קישור מכשיר ← "קשר באמצעות מספר טלפון".
2. **סריקת QR** — השאר את `PAIRING_PHONE_NUMBER` ריק, ובהפעלה יוצג QR לסריקה מהטלפון.

הסשן נשמר ב-`.wwebjs_auth/`, כך שהצימוד נדרש רק בפעם הראשונה.

## דשבורד ווב — צפייה ושליטה מהדפדפן

עם הפעלת הבוט עולה גם ממשק ווב ב-`http://127.0.0.1:3000` שמציג:

- **סטטוס חיבור** לוואטסאפ ומצב הסוכן (פעיל / האזנה בלבד)
- **צימוד מהדפדפן** — קוד הצימוד או ה-QR מוצגים ישירות בדף, בלי להסתכל בטרמינל
- **יומן אירועים חי** — הודעות נכנסות, תגובות שנשלחו, הפעלות Kill Switch
- **כפתורי הדלקה/כיבוי** — Kill Switch בלחיצה

הגדרות: `DASHBOARD_ENABLED`, `DASHBOARD_PORT`, `DASHBOARD_HOST`, `DASHBOARD_PASSWORD` (Basic Auth, שם משתמש `admin`). ללא סיסמה הדשבורד נגיש מהמחשב עצמו בלבד — ניסיון להאזין לכתובת חיצונית בלי סיסמה נחסם אוטומטית.

### גישה לדשבורד מהאינטרנט (מכל מקום)

הבוט עצמו לא צריך שום פתיחה לאינטרנט — הוא מתחבר החוצה לוואטסאפ. אם רוצים לפתוח גם את **הדשבורד** מרחוק, הדרך הבטוחה היא מנהרה, בלי לפתוח פורטים בראוטר:

1. **הגדר סיסמה חזקה** ב-`.env`: `DASHBOARD_PASSWORD=...` (חובה!)
2. בחר מנהרה:
   - **Cloudflare Tunnel (חינם):** `cloudflared tunnel --url http://localhost:3000` — מדפיס כתובת `https://xxx.trycloudflare.com` שנגישה מכל מקום.
   - **ngrok:** `ngrok http 3000` — כתובת ציבורית זמנית עם HTTPS.
   - **Tailscale (הכי בטוח):** מתקינים על המחשב ועל הטלפון — הדשבורד נגיש רק למכשירים שלך, בלי כתובת ציבורית בכלל.
3. גלוש לכתובת מהטלפון/מחשב אחר והזדהה עם `admin` והסיסמה.

זכור שגם בלי הדשבורד יש לך שליטה מרחוק מלאה דרך וואטסאפ עצמו: `!bot-off` מהטלפון, וניתוק המכשיר המקושר מההגדרות.

## מנגנוני שליטה ובטיחות

### 1. הבוט כבוי כברירת מחדל
`BOT_ENABLED=false` — במצב הזה הבוט רק מאזין ומדפיס הודעות ללוג, **ולא עונה במקומך**. כדי להפעיל מענה: `BOT_ENABLED=true` ב-`.env`, או פקודת ההדלקה מהטלפון.

### 2. Kill Switch — כיבוי חירום מרחוק
שלח מהטלפון שלך (מכל שיחה, כולל "הודעות לעצמי") את אחת הפקודות:

- `!bot-off` — כיבוי מיידי, חזרה ל-Read-Only (למקרה שהסוכן מתחיל להזות או לענות תשובות לא רצויות)
- `!bot-on` — הדלקה מחדש

הפקודות מזוהות דרך אירוע `message_create` (שנורה גם על הודעות שלך), ולכן עובדות מכל מקום בלי צורך בגישה לשרת.

### 3. מענה רק בתנאים מסוימים
- **מילת מפתח** (`TRIGGER_KEYWORD`, ברירת מחדל `!bot`) — הבוט מגיב רק להודעות שמתחילות בה, למשל: `!bot מתי אתה פנוי מחר?`
- **רשימת מספרים מורשים** (`ALLOWED_NUMBERS`) — הגבלת המענה לאנשי צוות או מספרי בדיקה בלבד
- **קבוצות** — הבוט מתעלם מקבוצות (`@g.us`) אלא אם `RESPOND_IN_GROUPS=true`

### 4. מניעת לולאה אינסופית
הודעות שנשלחו ממך (`msg.fromMe`) לעולם לא מקבלות תגובה.

## חיווי אנושי (Humanizing)

מטא חוסמת מספרים פרטיים שמפגינים התנהגות "בוטית" (מענה תוך מאית שנייה). לכן לפני כל שליחה הבוט:

1. מדליק חיווי **"מקליד..."** (`chat.sendStateTyping()`)
2. ממתין השהיה אקראית בטווח `MIN_REPLY_DELAY_MS`–`MAX_REPLY_DELAY_MS` (ברירת מחדל 2–5 שניות)
3. שולח את התגובה ומכבה את החיווי (`chat.clearState()`)

## הסוכן (Gemini / Claude)

- **שני ספקים נתמכים:** Gemini (Google) או Claude (Anthropic). הגדר `GEMINI_API_KEY` או `ANTHROPIC_API_KEY`. ברירת המחדל (`AGENT_PROVIDER=auto`) בוחרת Gemini אם קיים מפתח Gemini, אחרת Anthropic, אחרת מצב בדיקה.
- מודלים: `GEMINI_MODEL` (ברירת מחדל `gemini-2.5-flash`) או `AGENT_MODEL` (ברירת מחדל `claude-opus-4-8`)
- שומר היסטוריית שיחה נפרדת לכל צ'אט (עד `AGENT_HISTORY_TURNS` תורות) כדי לענות בהקשר
- **מצב ביטוח** (`INSURANCE_ONLY=true`, ברירת מחדל): עונה ישירות רק על ביטוח, מעביר את השאר לאישור (ראה למטה). **מצב כללי** (`INSURANCE_ONLY=false`): עונה על כל הודעה ישירות — נוח לבדיקה מהירה.
- אם הקריאה ל-API נכשלת או שהמודל לא החזיר טקסט — הבוט **שותק** במקום לשלוח תגובה שגויה

## הערה חשובה

`whatsapp-web.js` היא ספרייה לא רשמית שמפעילה WhatsApp Web דרך דפדפן. שימוש אוטומטי במספר פרטי מנוגד לתנאי השימוש של WhatsApp ועלול לגרום לחסימת המספר — מנגנוני החיווי האנושי מקטינים את הסיכון אך לא מבטלים אותו. לשימוש עסקי רשמי שקול את WhatsApp Business API.
